# tools/guide/ — 운영 가이드북 만들기

`안내자료/스마트점핑 운영 가이드북.html` 과 `.pdf`(A4 38쪽)를 만드는 자리입니다.
화면을 말로 설명하지 않고 **실제 사이트를 캡처해 번호를 찍어** 짚습니다.

## 한 번에 다시 만들기

```
npm run serve          # 8790 에 사이트를 띄워 둔다 (다른 창에서 계속 실행)
npm run guide:shots    # 캡처 → WebP  (Chrome + puppeteer-core + sharp 필요)
npm run guide:measure  # 콜아웃 좌표 재측정 → centers.json
npm run guide          # HTML + PDF
```

글만 고쳤다면 `npm run guide` 하나면 됩니다. 캡처는 사이트 화면이 바뀌었을 때만
다시 찍습니다.

`puppeteer-core` 와 `sharp` 는 선택 의존성입니다. 캡처·PDF 를 돌리려면
`npm i -D puppeteer-core sharp` 를 한 번 해 두세요. 크롬이 다른 곳에 깔려 있으면
`CHROME_PATH` 환경변수로 알려 줍니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `template.html` | 가이드북 본문. 그림 자리는 `__IMG_01__` 같은 자리표시자로 비워 둔다 |
| `capture.js` | 로그인 상태·경로를 바꿔 가며 1440×900 2배율로 화면을 찍어 `raw/` 에 담는다 |
| `capture-extra.js` | 모달 안에서만 그려지는 수업 리포트, 카드 근접 컷 등 보완 캡처 |
| `mask-yt.js` | 1장 유튜브 캡처에서 계정 정보를 가려 `raw/` 에 굽는다 |
| `capture-sheet.js` | 구글 시트 화면(videos · categories 탭)을 찍는다. 시트 주소를 인자로 준다 |
| `optimize.js` | `raw/*.png` → 가로 1400px WebP (`shots/`). 원본은 저장소에 올리지 않는다 |
| `measure.js` | 콜아웃이 가리킬 요소의 중심을 %로 재서 `centers.json` 에 적는다 |
| `build.js` | 자리표시자에 그림을 base64 로 박아 단일 HTML 로 굽는다 |
| `pdf.js` | 그 HTML 을 인쇄용 CSS 그대로 A4 PDF 로 뽑는다 |
| `shots/*.webp` | 가이드북에 실린 그림 45장 (약 1.4MB). `yt-*` 아홉 장은 1장 유튜브 업로드 화면, `sheet-*` 두 장은 구글 시트 |
| `centers.json` | 측정한 좌표. 콜아웃을 새로 찍을 때 여기 값을 쓴다 |

## 1장 유튜브 화면은 스크립트로 못 찍는다

`yt-1` 부터 `yt-9` 까지 아홉 장은 유튜브 스튜디오 화면이라 **로그인한 사람이 직접 찍어 준 것**입니다.
캡처 스크립트가 만들지 못합니다. 화면이 바뀌어 다시 찍어야 하면 같은 순서로 받아
`raw/yt-1-account-menu.png` … `raw/yt-9-copy-link.png` 로 이름을 맞춰 넣고
`node tools/guide/optimize.js` 를 돌립니다.

| 파일 | 화면 |
|---|---|
| `yt-1-account-menu` | 유튜브 오른쪽 위 프로필 메뉴 |
| `yt-2-create-menu` | 내 채널의 만들기 › 동영상 업로드 |
| `yt-3-upload-modal` | 동영상 업로드 창 |
| `yt-4-file-pick` | 파일 고르기 대화상자 |
| `yt-5-details` | 세부정보 (제목 · 동영상 링크) |
| `yt-6-audience` | 시청자층 아동용 여부 |
| `yt-7-review` | 검토 |
| `yt-8-visibility` | 공개 상태 |
| `yt-9-copy-link` | 콘텐츠 목록의 공유 가능한 링크 복사 |

이 아홉 장은 남의 계정 화면이라 그대로 실으면 채널명과 동영상 링크가 인쇄됩니다.
`mask-yt.js` 가 원본에서 열다섯 군데를 가려 `raw/` 에 굽습니다. 계정 이름과 핸들, 프로필 사진
다섯 곳, 채널 배너와 채널명, 세부정보 화면의 동영상 링크와 파일 이름, 파일 고르기 창의 파일 이름입니다.

```
npm run guide:mask     # 사용설명서/*.png → raw/yt-*.png (가린 사본)
npm run guide          # 다시 굽기
```

원본은 `사용설명서/` 에 그대로 두고 손대지 않습니다. 그래서 몇 번을 돌려도 겹쳐 흐려지지 않습니다.
좌표는 원본 픽셀 기준이라 **캡처를 새로 받으면 좌표부터 다시 재야 합니다.**
가린 자리가 콜아웃이 가리킬 요소를 덮지 않았는지 눈으로 확인하세요.
채널 배너를 가릴 때 그 위에 떠 있는 만들기 메뉴까지 덮은 적이 있습니다.

## 구글 시트 화면

```
node tools/guide/capture-sheet.js "https://docs.google.com/spreadsheets/d/…/edit"
```

**시트 주소는 저장소에 적지 않습니다.** 이 저장소는 공개라 주소가 함께 공개됩니다. 돌릴 때 인자로 줍니다.
보기 권한만 있어도 찍히며, 오른쪽 위 참여자 사진은 스크립트가 가려서 저장합니다.
찍은 화면에는 '보기 전용' 표시가 남으므로 그림 설명에 그 사정을 적어 두었습니다.

## 콜아웃 좌표는 눈대중으로 찍지 않는다

번호 뱃지(`<span class="cal" style="left:…%;top:…%">`)는 `.shot` 기준 백분율입니다.
컨테이너 한가운데를 찍으면 엉뚱한 데를 가리킵니다 — 칩 목록처럼 가운데 정렬된
줄에서는 "왼쪽 부분"이 45.9% 이지 24% 가 아닙니다. 그래서 `measure.js` 로
**가리키려는 그 요소**의 중심을 직접 재서 씁니다.

캡처와 측정은 반드시 같은 뷰포트(1440×900, deviceScaleFactor 2)에서 돌아야
좌표가 맞습니다. 두 스크립트에 같은 값이 박혀 있습니다.

## 인쇄 지면에서 주의할 것

- A4 본문 폭은 약 695 CSS px 이라 `@media (max-width:900px)` 가 **인쇄에서도 걸립니다.**
  2단·3단 배치가 1단으로 풀려 버리므로 `@media print` 에서 되돌립니다.
- 세로로 긴 캡처(사이드바)는 폭에 맞추면 한 장이 세 쪽을 잡아먹습니다.
  `build.js` 가 WebP 헤더에서 실제 비율을 읽어 높이가 200mm 를 넘지 않는
  폭을 계산해 `.shot` 에 `--pw` 로 박아 둡니다.
- `.shot.narrow` / `.shot.mid` 가 명시도로 앞서므로 인쇄 규칙에도 같이 적어야 합니다.

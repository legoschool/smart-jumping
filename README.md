# 미래형학교체육 '스마트점핑' (Smart-Jumping)

교실에서 바로 쓰는 학교체육 수업 영상 플랫폼. 수업 전에 영상을 담아두고, 교실에서는 재생 버튼 하나로 한 차시를 진행합니다.

**▶ 데모 사이트 : https://legoschool.github.io/smart-jumping/**

## 두 가지 버전

| | 데모 (GitHub Pages) | 풀스택 (Apps Script + 구글 시트) |
|---|---|---|
| 위치 | `index.html` | `apps-script/` |
| 백엔드 | localStorage | 구글 시트 |
| 데이터 공유 | 브라우저 1대 | 계정 전체 |
| 회원가입·탈퇴 | ○ (이 브라우저 한정) | ○ |
| 비용 | 0원 | 0원 |

**프론트 코드는 두 버전이 100% 동일합니다.** `web/local-backend.js` 가 `google.script.run` 과 똑같은 인터페이스를 localStorage 위에 구현해서, 프론트는 자기가 어느 백엔드에 붙어 있는지 몰라도 됩니다.

## 담긴 영상

**실제 유튜브 공개 영상 59건.** 전부 아래를 통과한 것만 넣었습니다.

- oEmbed API 로 생존 확인 → 삭제·비공개 2건 자동 제외
- watch 페이지의 `playableInEmbed` 로 **외부 재생 허용** 확인 → 59건 전부 통과
- 재생시간은 `lengthSeconds` 실측값
- 썸네일 커버리지 100% (고해상도 53건 + 자동 대체 6건)

| 영역 | 세부 분류 | 영상 |
|---|---|---|
| 명상 | 호흡 명상 · 마음챙김 명상 | 5 |
| 시간타이머 | 휴식영상 타이머 · 카운터 타이머 | 8 |
| 준비운동 \| 타바타 | 몸풀기&스트레칭 · 타바타&기초체력 · 기초체력 추천 조합 · 점핑 근력운동 | 17 |
| 스마트점핑 | 급수 친구들 1~3단계 · 쌩쌩이·2단뛰기 · 응용·심화 · 지도자 필수교육 | 17 |
| 비트 트레이닝 | 동요 율동 · 체조 메들리 | 7 |
| Killing Time Zone | 나라별 국기맞추기 · 숨은그림 찾기 | 5 |

> 영상은 모두 각 유튜브 채널의 원본을 임베드로 재생합니다. 저작권은 각 채널에 있으며, 이 저장소는 영상을 재배포하지 않습니다.

## 구글 시트 연동판 설치

### 1. 시트 채우기 — 둘 중 하나

**A. XLSX 가져오기 (Apps Script 없이, 가장 빠름)**

1. `스마트점핑_DB.xlsx` 다운로드
2. 구글 시트 열기 → **파일 → 가져오기 → 업로드**
3. 파일 선택 후 **스프레드시트 바꾸기** → 가져오기

9개 탭이 그대로 들어갑니다. (영상 59건 · 카테고리 18 · 수업 6 · 교재 12)

**B. Apps Script 로 자동 생성**

`apps-script/00_설정.gs` 의 `TARGET_SHEET_ID` 에 본인 시트 ID를 넣고 `초기설정_실행()` 실행.
시트 URL 의 `/d/` 와 `/edit` 사이 문자열이 시트 ID입니다.

```
https://docs.google.com/spreadsheets/d/  ← 여기부터  →  /edit
                                       1AbCdEf...
```

시트에서 **확장 프로그램 → Apps Script** 로 열었다면 `TARGET_SHEET_ID` 를 비워둬도 그 시트를 자동으로 채웁니다.

### 2. 웹앱 배포

<https://script.google.com> → 새 프로젝트 → 아래 6개 파일을 붙여넣습니다.

| 편집기에서 만들 파일 | 종류 |
|---|---|
| `00_설정` | 스크립트 |
| `01_초기설정` | 스크립트 |
| `02_API` | 스크립트 |
| `index` | **HTML** |
| `css` | **HTML** |
| `js` | **HTML** |

> `index` / `css` / `js` 는 반드시 **HTML 파일**로. 확장자는 붙이지 않습니다. 기본 `코드.gs` 는 지웁니다.

**배포 → 새 배포 → 웹 앱** / 실행 계정 **나** / 액세스 **링크가 있는 모든 사용자**

| 탭 | 열 |
|---|---|

| `classes` | 수업ID, 소유자, 수업년월, 지역, 학교, 학년, 반, 정원, 메모 |
| `attendance` | 수업ID, 학생명, 날짜, 출결 |
| `equipment` | 소유자, 교구명, 대리점명, 새제품수량, 중고제품수량, 수정일 |
| `schedules` | 소유자, 그룹명, 차시, 영상ID목록 |
| `textbooks` | 권차, 제목, 표지URL, 뷰어링크, 뱃지 |
| `playlists` | 소유자, 담은영상ID목록, 수정일 |

### 영상 추가
`videos` 탭에 행을 추가하고 `youtube_id` 에 영상 ID를 넣으면 끝입니다.

```
https://www.youtube.com/watch?v=AbCdEfGh123   →   AbCdEfGh123
https://youtu.be/AbCdEfGh123                  →   AbCdEfGh123
```

### 카테고리 변경
`categories` 탭을 고치면 상단 메뉴와 필터칩이 그대로 따라옵니다. **영상이 0건인 분류는 화면에 나타나지 않으므로**, 분류를 미리 다 적어두고 영상을 채워가도 화면이 깨지지 않습니다.

### ⚠ 시트를 직접 고친 뒤에는
영상·카테고리는 6시간 캐싱됩니다. 즉시 반영하려면 Apps Script 에서 **`캐시비우기`** 를 실행하세요.

## 알아둘 점

1. **속도** — Apps Script 왕복은 0.5~2초입니다. 서버 6시간 + 브라우저 이중 캐싱을 걸어두었고 로딩 중에는 스켈레톤이 뜹니다.
2. **로그인 보안** — 비밀번호는 SHA-256 해시로 저장합니다. 교내용 수준이지 은행급은 아닙니다. 실제 학교 계정을 받아 운영할 계획이면 구글 로그인으로 전환하는 편이 안전합니다.
3. **데모 사이트** — 백엔드가 없습니다. 데이터는 방문자 브라우저에만 저장되고 서로 공유되지 않습니다. 콘솔에서 `sjReset()` 을 실행하면 초기화됩니다.
4. **동시 사용** — 시트 쓰기에는 `LockService` 잠금이 걸려 있습니다.
5. **재생 오류** — 임베드가 막힌 영상을 만나면 안내를 띄우고 5초 뒤 자동으로 다음 영상으로 넘어갑니다.
